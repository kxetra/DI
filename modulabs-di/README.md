# 집값 예측 컴피티션: 회귀 모델 개선 기록 (38,019에서 20,215까지)

**AI 데이터 인텔리전스 › 필수 머신러닝 › 집값 예측 컴피티션** · [Modulabs-DI2기] House Price Prediction (Kaggle, 지표 RMSE)

Ames 주택 데이터로 집값(SalePrice)을 예측한 과제다. 템플릿의 전처리 버그를 고친 1차 제출(38,019)에서 시작해,
**train만으로 미리 정한 규칙에 따라 교차검증으로 고른 공정 모델**을 한 번 제출했다(리더보드 **20,215**).

> 중간에 이상치 기준·보정 강도 등을 **리더보드 점수를 보고** 골라 18,150(당시 1위)을 얻었지만, 이는 test 정보를 간접적으로 쓴 튜닝이라 공정한 성능이 아니다.
> 그 과정은 버리지 않고 `02_학습용/이전_리더보드튜닝본/`에 반면교사로 남겼다.

## 최종 모델

- 전처리: 결측을 학습 데이터의 중앙값·최빈값으로 채우고 원-핫 인코딩 (교차검증에서는 fold마다 따로)
- 이상치: '아주 큰데 싼 집' 2채 + 잔차 3σ 이상 집을 학습에서 제외
- 모델: GBR(깊이 3) · GBR(깊이 4) · XGBoost의 log(집값) 예측 평균
- CV RMSE 27,956 (검증 fold의 모든 집 채점) · 리더보드 20,215 (1회 제출)

## 실행 방법

대회 데이터(`train.csv`, `test.csv`, `sample_submission.csv`)는 비공개 대회 자료라 저장소에 포함하지 않았다.
대회 페이지에서 받아 이 폴더(`modulabs-di/`)에 두고 노트북을 **Restart → Run All** 하면 된다(약 25분).
환경: Python · scikit-learn 1.9 · pandas 3.0 · xgboost 3.4
