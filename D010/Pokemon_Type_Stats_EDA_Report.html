분석 질문: 포켓몬의 1차 타입에 따라 6개 기본 종족값(HP/공격/방어/특수공격/특수방어/스피드)은 어떻게 다른가? 기본 종족값 총합이 높은 개체는 무엇인가?

원본 웹페이지: https://pokemondb.net/pokedex/all (전체 타입·능력치 HTML 표)

수집 방식의 정확한 상태: 이 보고서는 웹에서 내용 확인 후 전사·교차검증한 전국도감 1~70번 기본형 표본을 이용한 오프라인 EDA입니다. 생성 환경의 직접 HTTP 연결 실패로 실시간 자동 스크래핑은 수행되지 않았습니다. 별도 첨부한 Jupyter 노트북에는 실제 URL에 requests.get을 요청하고 BeautifulSoup으로 추출하는 실행 가능한 전 과정이 포함되어 있습니다.

범위: 번호 1~70 기본형, 1차 타입 11종. 같은 번호의 특수폼을 제외하였으며, 총 18개 타입 전체나 전체 세대 결과로 해석할 수 없습니다.

01 · HTTP 요청

requests로 웹페이지에 GET 요청. 상태 코드를 검사하고 본문을 받는다.

resp = requests.get(URL, timeout=15)
resp.raise_for_status()
html_text = resp.text
02 · 페이지 유형

받은 HTML에 통계 표가 존재하면 정적 HTML 수집이 가능하다.

soup = BeautifulSoup(html_text, "html.parser")
table = soup.select_one("table#pokedex")
03 · HTML 구조

tbody 아래 각 tr이 포켓몬 하나; td 10개에 번호·이름·타입·능력치가 있다.

rows_html = table.select("tbody tr")
print(len(rows_html))
04 · 구조화 추출

행을 반복하고, 타입 아이콘·이름·수치 열을 읽어 리스트에 저장한다.

for tr in rows_html:
    tds = tr.select("td")
    name = tds[1].select_one("a.ent-name").get_text(strip=True)
    types = [a.get_text(strip=True) for a in tds[2].select(".type-icon")]
    rows.append({"name": name, "type1": types[0], ...})
05 · pandas 정제

한 전국도감 번호의 폼이 여러 개면 기본형 첫 행만 남기고 수치형을 검증한다.

df = pd.DataFrame(rows)
base = df.drop_duplicates("national_no", keep="first")
base["attack"] = pd.to_numeric(base["attack"])

EDA ① 타입 분포와 평균 능력치 총합
